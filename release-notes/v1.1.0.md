Unduh **kotoba-android.apk** pada bagian Assets, lalu instal langsung di HP. Tidak perlu mengekstrak ZIP. Android 8.0+ ARM64; sekitar 533 MB karena model VOICEVOX dibundel.

- Pilih **Microsoft Edge · online** untuk Nanami dan Keita langsung dari HP, tanpa server laptop atau API key Azure. Internet diperlukan saat membuat/preview audio.
- **VOICEVOX · offline** tetap tersedia dengan karakter/gaya yang sudah dipilih.
- Audio hasil kedua provider dapat diputar saat membuka aplikasi lain atau layar mati, dengan kontrol media Android.
- Jepang, romaji, dan arti Indonesia mengikuti posisi pemutaran, termasuk setelah seek dan kembali ke aplikasi.
- Mode Alami VOICEVOX memperhalus bunyi panjang dan akhir pertanyaan tanpa menghapus mora Jepang.

Build debug untuk penggunaan pribadi. Kunci pemasangan sama dengan build v1.0.0 terakhir. Instal APK sebagai pembaruan; tidak perlu menghapus aplikasi lama. Pengujian otomatis meliputi protokol Microsoft, sintesis online Nanami/Keita di emulator Android, VOICEVOX offline, dan pemutaran background/layar mati. Tecno fisik belum diuji.
