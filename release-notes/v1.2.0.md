Dua APK tersedia langsung di Assets:

- **kotoba-lite.apk** — Microsoft online saja: Nanami dan Keita. Tidak menyertakan model, kamus Jepang, atau library native VOICEVOX; langsung siap tanpa penyiapan model.
- **kotoba-full.apk** — Microsoft online + seluruh pilihan VOICEVOX offline seperti versi sebelumnya. Pasang sebagai pembaruan aplikasi Kotoba lama.

Keduanya tetap mendukung pemutaran background, layar mati, kontrol media Android, pengaturan tempo, unduh WAV, dan subtitle Jepang/romaji/Indonesia yang mengikuti posisi audio. Internet hanya diperlukan untuk membuat/preview audio Microsoft; hasilnya dapat diputar offline.

Lite bernama **Kotoba Lite** dengan ID aplikasi terpisah, sehingga bisa dipasang bersamaan dengan **Kotoba Full**. Data masing-masing aplikasi terpisah. Keduanya Android 8.0+; Full memerlukan CPU ARM64, sedangkan Lite tidak membawa library native.

Pengujian mencakup sintesis Nanami/Keita sesungguhnya, background/layar mati pada kedua APK, sintesis VOICEVOX pada Full, dan pemeriksaan isi Lite agar model/native library tidak ikut terpaket. Build debug untuk pemasangan pribadi; pengujian Tecno fisik belum dilakukan. File SHA256SUMS memuat checksum kedua APK.
